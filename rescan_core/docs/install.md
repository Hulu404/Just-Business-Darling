# Установщики и приложения: что нужно и зачем

Список минимальный. Всё бесплатное, лицензий покупать не нужно.

## Обязательно

| Приложение | Версия | Скачать | Зачем нужно | Проверка |
|---|---|---|---|---|
| **Python** | 3.13.x | python.org/downloads | Язык, на котором написан бэкенд | `python --version` |
| **PostgreSQL** | 16.x | postgresql.org/download | Основная база данных. При установке вместе с ней ставится `psql` | `psql --version` |
| **Git** | последняя | git-scm.com | Версии кода, клонирование репозитория | `git --version` |
| **VS Code** | последняя | code.visualstudio.com | Редактор + запуск тестов + отладка | — |

## Расширения VS Code (не отдельные программы)

Ставятся из панели Extensions или сами подтянутся из `.vscode/extensions.json`:

| Расширение | Зачем |
|---|---|
| **Python** (ms-python.python) | запуск, отладка, интерпретатор |
| **Pylance** (ms-python.vscode-pylance) | подсказки и проверка типов |
| **Ruff** (charliermarsh.ruff) | стиль и автоисправление |
| **Mypy Type Checker** (ms-python.mypy-type-checker) | строгая проверка типов |
| *(необязательно)* **SQLite** (alexcvzz.vscode-sqlite) | открыть тестовую `.db`-базу прямо в редакторе |

## Для работы с базой

| Приложение | Есть у тебя? | Зачем |
|---|---|---|
| **DBeaver** | ✅ да | Смотреть таблицы, данные, писать SQL-запросы. Подключение описано в `docs/for-you.md` |

Никаких других СУБД-клиентов не нужно — DBeaver закрывает всё.

## Необязательно, но удобно

| Приложение | Зачем |
|---|---|
| **Insomnia** (insomnia.rest) или **Postman** | Дёргать API руками; можно заменить скриптом `send_event.py` |
| **Docker Desktop** | Если захочешь поднять PostgreSQL одной командой вместо установщика. Не требуется |

## Чего устанавливать НЕ надо

- Никаких языковых моделей и ИИ-клиентов для этого проекта.
- Отдельный сервер (nginx и т.п.) — для локальной разработки хватает `uvicorn`.
- Платные приложения и подписки — ничего из них не нужно.

## Порядок установки (рекомендуемый)

1. Python 3.13 (галочка «Add Python to PATH» — обязательно).
2. PostgreSQL 16 (запомни пароль `postgres`).
3. Git.
4. VS Code + расширения.

После этого — сразу к `docs/setup.md`, раздел 2 (создание базы).
