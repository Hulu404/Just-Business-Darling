## Ограничения

- «Лечение» — пустое состояние: назначений врача в API пациента нет.
- Профиль не редактируется: «Личные данные и уведомления на стенде не настраиваются».
- `--web-check` красный из-за задержек общей базы; предложение команде — отдельная локальная PostgreSQL для проверок в браузере.
